# Abiodun Matthew Otitoloju — Portfolio

Personal portfolio website for Abiodun Matthew Otitoloju, Full Stack Software Developer.

🌐 **Live site:** https://Bmat321.github.io

## Stack
- Pure HTML / CSS / JavaScript — no build step needed
- Auto-deployed via GitHub Actions on every push to `main`

## Local preview
Just open `index.html` in your browser.

## Deployment
Every time you push changes to the `main` branch, GitHub Actions automatically deploys the latest version to GitHub Pages. No manual steps needed.

## Making edits
- Open `index.html` in any text editor (VS Code recommended)
- Make your changes
- Commit and push to `main` — the site updates in ~1 minute
